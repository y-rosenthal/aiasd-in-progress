Midterm, Version A

The Fall 2026 midterm exam, Version A, as it was given.

  • The exam: PDF · Word
  • The answer key (PDF): the exam with the correct answers circled in green

The three versions have the same questions and the same answer choices, in a different order. The test papers do not show the version; question 1 tells them apart:

  • Version A (this page): “The task app is written with Next.js, which is a framework. What is a …”
  • Version B: “What does it mean to distill an AI …”
  • Version C: “You have step-by-step instructions, plus a small program, for turning your …”

Under each question, click Answer to see the correct answer and why each choice is correct or wrong.

Part 1: Multiple choice

Question 1 · Multiple choice

The task app is written with Next.js, which is a framework. What is a framework?

  1. Ready-made code and structure that you build your own app on.
  2. A database that stores an app’s data in tables.
  3. A company’s servers that host a website at a public address.
  4. An outside service that handles an app’s logins and payments.
  5. A tool that tests an app and finds its bugs before release.
Answer

a. Ready-made code and structure that you build your own app on.

A framework is ready-made code plus a standard structure for a certain kind of app. You write only the parts that are special to your app. The framework does the common jobs, such as moving between pages and talking to the server.

Why the other answers are wrong:

  • b. This describes a database. In the task app, the PostgreSQL database on Supabase stores the data in tables. Next.js does not store the app’s data.
  • c. This describes hosting. In the task app, Vercel hosts the website at a public address. Next.js is the code that the app is built with, not the computers that run it.
  • d. This describes third-party services. In the task app, Supabase handles logins and Stripe handles payments. A framework is code that you build on, not an outside service.
  • e. This describes a testing tool. A framework gives you the structure and code to build an app. It does not test the app or find its bugs.

Question 2 · Multiple choice

A startup is choosing a programming language for a new product. What should it take into account?

  1. Which language needs the fewest lines of code to write.
  2. Which language is the least popular, so fewer attackers know its flaws.
  3. What the product must do, and where it will run (browser, phone, server).
  4. Which language is the newest, since newer languages run faster.
  5. Which language looks most like plain English, so customers can read it.
Answer

c. What the product must do, and where it will run (browser, phone, server).

Fit for purpose comes first. Each language was designed for certain jobs and places: the browser runs JavaScript, and Swift is Apple’s language for iPhone apps. So what the product must do, and where its code runs, decide much of the choice.

Why the other answers are wrong:

  • a. Fewer lines of code do not make a program run better or scale better. How fast people can write the code is a small, real factor, but it is not the first thing to consider. When AI writes much of the code, it matters more that people can read the code easily.
  • b. The opposite is true. Many people use and check a popular language, so its flaws are found and fixed quickly. A popular, mature language is also more likely to be supported and patched for many years.
  • d. Newer languages do not run faster in general. A new language also has fewer developers who know it, fewer packages, and fewer public answers to common problems.
  • e. Customers never read the code. They use the finished product. The code is read by developers and by AI tools.

Question 3 · Multiple choice

Which part of the task app is its front end?

  1. The storage area that holds the images users upload.
  2. The app’s pages, buttons and forms that the user clicks on.
  3. The login system that checks users’ emails and passwords.
  4. The service that charges users for the Premium plan.
  5. The PostgreSQL database that holds every user’s tasks.
Answer

b. The app’s pages, buttons and forms that the user clicks on.

The front end is the part of the app that runs in the user’s browser. It is the pages, buttons and forms, made of the HTML, CSS and JavaScript that Next.js produces.

Why the other answers are wrong:

  • a. The storage area for uploaded images is a Supabase storage bucket. It runs on Supabase’s servers, so it is part of the back end.
  • c. The login form is on a page, but the system that checks emails and passwords is Supabase authentication. It runs on Supabase’s servers, so it is part of the back end.
  • d. Payments for the Premium plan are handled by Stripe, on Stripe’s servers, so they are part of the back end. The app’s pages do not ask Stripe directly: an Edge Function on Supabase asks Stripe for the checkout page.
  • e. The PostgreSQL database runs on Supabase’s servers, so it is part of the back end. The browser reaches it only through Supabase’s Data API.

Question 4 · Multiple choice

What is recursive self-improvement (RSI)?

  1. AI does much of the work of building the next, more capable AI, which builds an even better one.
  2. A model checks and rewrites its own answer several times before showing it.
  3. A chatbot remembers earlier chats and uses them to give better answers.
  4. A smaller model is trained on a larger model’s answers until it is almost as good.
Answer

a. AI does much of the work of building the next, more capable AI, which builds an even better one.

In RSI, AI creates the next version of AI. That version is smarter and builds an even better one, and the cycle repeats. People may no longer understand or control the result.

Why the other answers are wrong:

  • b. This describes a reasoning (thinking) model, which works through intermediate steps before it gives its final answer. The model itself does not become more capable.
  • c. This describes an app’s memory feature, which adds saved notes from earlier chats to the context window. The model’s weights do not change, so the AI does not improve itself.
  • d. This describes distillation: training a model on another model’s answers so that it learns to imitate it. Here a model copies another model. No AI builds a more capable next version.

Question 5 · Multiple choice

How do strong open-weight models affect the business of Anthropic and OpenAI?

  1. New income: people who download open-weight models pay license fees to the US labs.
  2. Little effect: open-weight models run only on the big labs’ special hardware.
  3. Pressure to cut prices, stay clearly better, or reinvent their business model.
  4. Little effect: open-weight models can’t be customized or trained further.
Answer

c. Pressure to cut prices, stay clearly better, or reinvent their business model.

Cheap, strong open-weight models give customers a low-cost choice. In 2026 this led to a price war: for example, OpenAI launched GPT-6 Sol and Luna at half the price of the models they replaced. The US labs must cut prices, stay clearly better, or change how they make money.

Why the other answers are wrong:

  • a. No such fee exists. Open-weight models are free to download, and many of the strongest ones come from Chinese labs, not from the US labs. People who download them do not pay Anthropic or OpenAI.
  • b. Anyone can download an open-weight model and run it on their own hardware, or use it through a hosting company’s API. Small models can even run on a laptop.
  • d. Anyone can fine-tune an open-weight model, which means to train it further on their own data. Some US products, such as Cursor’s Composer coding model, are built on Chinese open-weight models.

Question 6 · Multiple choice

Why is a prompt cache useful?

  1. The server reuses the already-processed part of the context window, so it is faster and much cheaper.
  2. It stores what you said in earlier chats, so the model learns your preferences and improves over time.
  3. It keeps the web pages that Claude Code searched on your computer, so later searches don’t use your limits.
  4. It gives higher plans extra memory, so the tokens stored there are free, although the plan costs more each month.
Answer

a. The server reuses the already-processed part of the context window, so it is faster and much cheaper.

Every message sends the whole conversation to the model again. The server reuses the unchanged beginning that it already processed. Reading this cached part is faster and billed at a much lower rate.

Why the other answers are wrong:

  • b. The model does not learn from your chats: its weights do not change while you chat. The cache holds only the already-processed start of the current conversation, and it expires after a time without use.
  • c. The prompt cache is on the model’s server, not on your computer, and it does not store web pages. It holds the processed start of the conversation that Claude Code sends.
  • d. The cache is not extra memory for higher plans, and cached tokens are not free. They are billed at a much lower rate. Higher plans give a bigger usage allowance, not a special cache.

Question 7 · Multiple choice

Which choice correctly describes both an LLM and an agent?

  1. LLM: search engine that merges web pages into one answer. Agent: LLM + tools, in a loop.
  2. LLM: rules written by programmers for each kind of question. Agent: LLM with a bigger context window.
  3. LLM: neural network trained on huge amounts of text; predicts the next token. Agent: smaller LLM trained on another LLM’s answers.
  4. LLM: neural network trained on huge amounts of text; predicts the next token. Agent: LLM + tools, in a loop.
Answer

d. LLM: neural network trained on huge amounts of text; predicts the next token. Agent: LLM + tools, in a loop.

An LLM is a neural network trained on huge amounts of text, and it predicts the next token. An agent is an LLM plus tools plus a loop: it acts, checks the result, and decides the next step.

Why the other answers are wrong:

  • a. The agent part is right, but the LLM part is wrong. An LLM is not a search engine: it does not look up and merge web pages. It predicts the next token from what it learned in training.
  • b. Both parts are wrong. Rules written by programmers describe classic programming; an LLM learns its patterns from examples instead. A bigger context window does not make a model an agent; an agent is an LLM with tools, in a loop.
  • c. The LLM part is right, but the agent part is wrong. A smaller model trained on another model’s answers describes distillation, not an agent.

Question 8 · Multiple choice

Which is an example of agentic AI, not just generative AI?

  1. An AI that composes background music for your video.
  2. An AI that creates a picture of a cat in outer space.
  3. An AI that searches airline websites and books a flight for you.
  4. An AI that writes a poem about your city when you ask for one.
Answer

c. An AI that searches airline websites and books a flight for you.

This AI uses tools to act: it browses airline websites and places a booking for you. Doing things with tools, not only creating content, is what makes AI agentic.

Why the other answers are wrong:

  • a. Composing music is generative AI: the AI creates content (audio). It does not use tools to take actions in the world.
  • b. Creating a picture is generative AI: the AI creates content (an image). Nothing outside the picture changes.
  • d. Writing a poem is generative AI: the AI creates content (text) when you ask. It does not act on anything outside the chat.

Question 9 · Multiple choice

A student on a paid Claude plan is suddenly blocked from using Claude Code in the middle of the afternoon. Which explanation fits how the limits work?

  1. Claude Code blocks all users for an hour each afternoon to save energy.
  2. Their subscription expired; subscriptions must be renewed every week.
  3. Their plan allows a fixed number of messages per day, whatever their size.
  4. They hit the limit for the current 5-hour window or the week; they must wait.
  5. Their context window filled up; the plan blocks them until tomorrow.
Answer

d. They hit the limit for the current 5-hour window or the week; they must wait.

Every plan has a limit for a rolling 5-hour window, and paid plans also have a weekly limit. When you reach a limit, you are blocked until it resets. Waiting is the basic fix; you can also upgrade or, on a paid plan, turn on usage credits.

Why the other answers are wrong:

  • a. Claude Code has no fixed daily break for all users. A block comes from your own usage, measured against your plan’s limits.
  • b. Subscriptions are billed by the month; there is no weekly renewal. The weekly limit is a usage limit that resets, not a subscription that expires.
  • c. A subscription does not give a fixed number of messages. It gives an allowance of work measured in tokens, so long conversations, big files and bigger models use it up faster.
  • e. The context window is the length limit of one conversation, not a usage limit. When it fills up, you use /clear or /compact, or Claude Code compacts automatically. It does not block you until tomorrow.

Question 10 · Multiple choice

Which choice correctly describes both AGI and superintelligence?

  1. AGI: AI whose weights are published. Superintelligence: the most capable closed model.
  2. AGI: AI that improves its own code. Superintelligence: AI that uses tools such as web search.
  3. AGI: very good at one task, such as chess. Superintelligence: good at many tasks.
  4. AGI: matches humans at most thinking tasks. Superintelligence: far beyond the best humans.
Answer

d. AGI: matches humans at most thinking tasks. Superintelligence: far beyond the best humans.

AGI is AI that matches humans at almost all thinking tasks. Superintelligence is AI far better than the best humans in nearly every field. Both are hypothetical today.

Why the other answers are wrong:

  • a. An AI whose weights are published is an open-weight model, and a model that only its maker runs is a closed model. These terms describe how a model is shared, not how capable it is compared with humans.
  • b. AI that improves its own code is closer to recursive self-improvement (RSI), and using tools such as web search is what an agent does. Neither describes AGI or superintelligence.
  • c. An AI that is very good at one task, such as chess, is narrow AI, not AGI. And being good at many tasks is not enough for superintelligence: it must far surpass the best humans.

Question 11 · Multiple choice

Why have AI companies such as Anthropic and Google worked so hard to make their models good at coding?

  1. New laws require AI models to pass a coding test before release.
  2. Most of their paying customers are professional programmers.
  3. Code is shorter than English, so training on code costs less.
  4. A model that writes programs can do anything a program can do.
Answer

d. A model that writes programs can do anything a program can do.

If an AI can write a program to do something, it can do anything a program can do. This lets the AI extend its own capabilities, and it could eventually lead to recursive self-improvement (RSI).

Why the other answers are wrong:

  • a. No law requires AI models to pass a coding test before release. The focus on coding comes from what code lets an AI do.
  • b. Coding tools do sell well, but sales are not the main reason. The deeper reason is that coding ability lets an AI extend everything else it can do.
  • c. The focus on coding is not about saving money on training. Models are trained on huge amounts of text of all kinds. Labs focus on coding because of what programs can do, not because code is short.

Question 12 · Multiple choice

Which of these takes up space in Claude Code’s context window, even though you may not see it on the screen?

  1. The text of every file in your project.
  2. Your usage numbers, which Claude checks before each reply.
  3. The model’s thinking, as it works through different possibilities.
  4. The training data that the model read while it was being built.
  5. Your chats with Claude in other projects on the same computer.
Answer

c. The model’s thinking, as it works through different possibilities.

A reasoning (thinking) model writes out intermediate steps before its final answer. This thinking is part of the model’s output, so it goes into the context window even if you do not see it. Higher effort means more thinking and more tokens.

Why the other answers are wrong:

  • a. Only the files that Claude has opened are in the context window, not every file in the project. Each file that Claude reads does take space, even though you see only one line such as Read auth.ts.
  • b. Your usage is tracked on Anthropic’s side and shown by /usage. Claude does not read your usage numbers before each reply, and they are not part of the conversation.
  • d. Training data is not in the context window. What the model learned in training is stored in its weights, which are a different kind of memory.
  • e. Each session has its own context window. Chats in other projects are not in it, and a new chat starts without the earlier ones.

Question 13 · Multiple choice

Which of the following are in Claude Code’s context window for a particular chat?

  1. All the text that the model read while it was being trained.
  2. Only the last message you typed, and nothing that came before it.
  3. Only the messages from you and Claude that appear on the screen.
  4. Your messages, Claude’s replies, and a hidden system prompt.
  5. Every chat you have ever had with Claude Code, from the first one.
Answer

d. Your messages, Claude’s replies, and a hidden system prompt.

The context window holds all the text of the chat, typed by you or by the AI, plus the hidden system prompt. In Claude Code it can hold more, such as CLAUDE.md, skill descriptions and the files Claude reads, but this choice names the main parts correctly.

Why the other answers are wrong:

  • a. This confuses the context window with training. What the model read in training is stored in its weights, not in the context window of a chat.
  • b. Each time you send a message, the whole conversation so far is sent to the model again. The model needs the earlier messages to follow the conversation.
  • c. This leaves out the text that you do not see, most importantly the system prompt: hidden instructions from the company that runs the AI.
  • e. A new chat starts with an empty conversation. Earlier chats are not in its context window unless you go back to one, for example with /resume.

Question 14 · Multiple choice

After a very long Claude Code session, Claude starts ignoring a decision that you made about halfway through. What is the most likely cause?

  1. The model’s training cutoff date passed during the session.
  2. The context window has become very full.
  3. You hit your weekly limit, so Claude switched to a weaker model.
  4. The temperature slowly rose during the long session.
  5. The prompt cache expired while the session was running.
Answer

b. The context window has become very full.

This is context rot. As the context window fills up, the model gets worse at using what is in it. It tends to miss information in the middle of a long conversation most often.

Why the other answers are wrong:

  • a. The training cutoff is the fixed date when the model’s training data ends. It cannot pass during a session, and it has nothing to do with the messages in your chat.
  • c. When you hit a usage limit, you are blocked until the limit resets, unless you upgrade or use usage credits. Claude does not switch to a weaker model.
  • d. Temperature is a setting that controls how random the choice of the next token is. The app sets it, and it does not rise during a session.
  • e. When the prompt cache expires, the next reply costs more, because the server must process the whole conversation again at the full price. Claude still receives the whole conversation, so it does not forget anything.

Question 15 · Multiple choice

Why do LLMs work so well with Markdown files, compared with Word or Excel files?

  1. Markdown is a programming language that only LLMs can understand.
  2. Markdown files store pictures and charts in a form that LLMs prefer.
  3. Markdown is plain text (just keyboard characters), so the LLM reads it directly.
  4. Markdown was invented by Anthropic for use with Claude and Claude Code.
  5. Markdown files are encrypted, so the LLM can read them without risk.
Answer

c. Markdown is plain text (just keyboard characters), so the LLM reads it directly.

A Markdown file is plain text: only characters that you can type on a keyboard. An LLM works with text, so it can read and write Markdown directly.

Why the other answers are wrong:

  • a. Markdown is not a programming language, and it is not only for LLMs. It is a simple notation for formatting plain text, and any person can read it.
  • b. A Markdown file contains only text. It can link to an image, but the picture itself is a separate file. Pictures and charts are what make Word and Excel files harder for an LLM.
  • d. Anthropic did not invent Markdown. It is a general format that existed long before Claude; for example, README.md files on GitHub use it.
  • e. Markdown files are not encrypted. They are plain text that anyone can open and read in any text editor. An encrypted file cannot be read without its key.

Question 16 · Multiple choice

During training, a model reads a sentence and predicts the next word, but its prediction is wrong. What happens next?

  1. A person adds a rule that gives the correct word for that sentence.
  2. The model saves the sentence, so it can look up the right word later.
  3. The model marks the sentence as wrong and skips it from then on.
  4. The model adjusts itself slightly, so the right word is a bit more likely.
Answer

d. The model adjusts itself slightly, so the right word is a bit more likely.

After a wrong prediction, the model changes its weights very slightly. The next time, the right word is a bit more likely.

Why the other answers are wrong:

  • a. Nobody writes rules for a language model. Writing rules is classic programming; in machine learning, the model learns from examples by itself.
  • b. The model does not keep a copy of the text to look up later. What it learns is stored as small changes to its weights, not as saved sentences.
  • c. The model does not skip text after a wrong guess. It reads its training data many times, and each wrong guess is a chance to adjust itself.

Question 17 · Multiple choice

Claude Code uses the Claude Opus 5.5 model. Which describes their roles correctly?

  1. Claude Code is a model trained only for coding; Opus 5.5 is the subscription plan that it runs on.
  2. Both are models; Claude Code is a smaller, faster version of Opus 5.5.
  3. Claude Code generates the next word; Opus 5.5 is the harness that runs commands on your computer.
  4. Opus 5.5 generates the next word; Claude Code is the harness that gives it tools to act.
Answer

d. Opus 5.5 generates the next word; Claude Code is the harness that gives it tools to act.

Opus 5.5 is the model: it generates the next word. Claude Code is the harness: it gives the model tools and runs them. More exactly, a model generates the next token, which is a word or part of a word; the question says “word” to keep it simple.

Why the other answers are wrong:

  • a. Claude Code is not a model; it is a program that uses a model. Opus 5.5 is not a subscription plan; it is a model. Plans are things such as Pro and Max.
  • b. Claude Code is not a model at all, so it is not a smaller version of Opus 5.5. It is the software that sends your requests to a model and runs tools for it.

You move a file to another folder by typing a command in a terminal. Your friend does the same by dragging the file’s icon. Which is correct?

  1. You used a CLI, which needs the Internet; your friend used a GUI, which works offline.
  2. You used a GUI; your friend used a CLI. Both can do the same job.
  3. You used a CLI; your friend used a GUI. Both can do the same job.
  4. You used a CLI, which can only manage files; your friend used a GUI, which can do anything.
Answer

c. You used a CLI; your friend used a GUI. Both can do the same job.

Typing a command in a terminal is using a CLI (command-line interface), and dragging an icon is using a GUI (graphical user interface). Both can move the file.

Why the other answers are wrong:

  • a. Neither a CLI nor a GUI needs the Internet in general; both control your own computer. Some CLI tools need the Internet, such as Claude Code, which talks to a model online, but a command that moves a file works offline.
  • b. This swaps the two terms. Typing a command in a terminal is using a CLI, and dragging an icon is using a GUI.
  • d. A CLI can control all parts of the computer, not only files. Most jobs can be done with either a CLI or a GUI.

Question 44 · Matching

Match each term with its meaning. Two meanings are not used. (10 points)

Item Choice
1. Jailbreak A. A prompt designed to get around a model’s safety rules
2. Misalignment B. The maximum amount of text that the model can consider at once
3. Token C. A small piece of text, often part of a word; models read and write text in these units
4. Frontier model D. The date when the data that a model was trained on ends
5. Context window E. One of the most capable general-purpose models, matching or beating today’s best
F. Instructions hidden in content that the AI reads, such as a web page or an email
G. AI that pursues goals that conflict with what people intend
Answer

1A, 2G, 3C, 4E, 5B

This part was not graded: everyone was told to skip the matching questions.

  • 1. Jailbreak → A (A prompt designed to get around a model’s safety rules). A jailbreak is a prompt that tries to get a model to do or say what its safety rules forbid. The person who types the prompt is the attacker.
  • 2. Misalignment → G (AI that pursues goals that conflict with what people intend). Alignment means an AI uses its abilities the way people intend. Misalignment means the AI pursues goals that conflict with those intentions.
  • 3. Token → C (A small piece of text, often part of a word; models read and write text in these units). A tokenizer splits text into tokens before the model sees it. A common word is often one token, and a longer or rarer word is split into pieces.
  • 4. Frontier model → E (One of the most capable general-purpose models, matching or beating today’s best). A frontier model is one of the most capable general-purpose models available, matching or beating today’s best.
  • 5. Context window → B (The maximum amount of text that the model can consider at once). The context window is the maximum amount of text, measured in tokens, that the model can consider at once.
  • D is not used (The date when the data that a model was trained on ends). This meaning defines the knowledge cutoff (training cutoff): the date when the model’s training data ends.
  • F is not used (Instructions hidden in content that the AI reads, such as a web page or an email). This meaning defines prompt injection. The attacker hides instructions in content that the AI reads, and the user is the victim, not the attacker.
