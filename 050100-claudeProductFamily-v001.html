41  41. The Claude Product Family

“Claude” is the name of an AI model, a chat app, a coding tool, and a developer platform. This page is a map of all of them: what each piece is, where it runs, and who it is for. Later pages cover the pieces this course uses most, especially Claude Code.

41.1 One name, four meanings

As of Oct 6, 2026 · Official docs: Models overview · What interfaces can I use to access Claude?

When someone says “Claude”, they can mean four different things:

Someone says… They mean…
“Opus is smarter than Haiku.” Claude the model: the AI itself, a family of large language models made by the company Anthropic (see Claude Models, Plans, and Usage Limits).
“I asked Claude to summarize my notes.” The Claude apps: the chat website claude.ai and the desktop and mobile apps.
“Claude Code fixed my bug.” Claude Code: Anthropic’s coding agent, which reads your project, edits files, and runs commands. It is this course’s main tool.
“Our app calls Claude.” The Claude API: a way for programs to send requests to Claude and pay for each use.

Think of the model as an engine and the rest as vehicles built around it. Each vehicle adds its own controls and tools, so the same model can act differently in each (see How Claude Code Works).

“Paid” means the Pro, Max, Team, or Enterprise plan. The plans are compared on the next page.

41.3 The Claude apps: web, desktop, and mobile

As of Oct 6, 2026 · Official docs: Install Claude Desktop · Claude Cowork and chat are one Claude

  • claude.ai works in any browser, on every plan including Free.
  • Claude Desktop is the installed app for Mac and Windows (Linux is in beta). Besides chat, it can work with folders on your computer, connect to local tools, and has a Code tab that runs Claude Code with buttons and panels instead of a terminal (paid plans).
  • Claude mobile (iPhone and Android) offers chat, spoken conversations (voice mode, in beta), and a way to check on longer tasks. Its Code tab connects to Claude Code sessions (see Claude Code Beyond the Terminal).

41.3.1 Cowork is becoming plain “Claude” (rolling out)

As of Oct 6, 2026 · Official docs: Claude Cowork and chat are one Claude · Cowork is now Claude

Cowork was a separate mode for handing Claude a longer, multi-step job, such as research, a report, a spreadsheet, or a slide deck. It is built on the same technology as Claude Code, but for work that isn’t coding. On September 16, 2026, Anthropic started merging chat and Cowork into one conversation: you just ask, and Claude decides whether you need a quick answer or a longer task that keeps running in the cloud after you close your laptop.

The change is rolling out in stages, starting with Pro and Max. If your message box still shows separate “Chat” and “Cowork” options, you have the older experience. Either way, the Desktop Code tab stays where it was.

41.4 Features inside the apps

As of Oct 6, 2026 · Official docs: What are projects? · What are artifacts? · What are skills?

Feature In one sentence
Projects A workspace that keeps related chats together with uploaded files and standing instructions (Free plan: up to 5 projects).
Artifacts Something Claude makes that you would show to someone, such as a document, deck, design, dashboard, or small interactive tool; it opens beside the chat, and you can share it by link.
Claude Design, Slides, Docs Artifact templates (beta, paid plans) for designs and mockups, presentations (export to PowerPoint or PDF), and “living documents” that you edit together with Claude and your teammates.
Memory Claude remembers useful context across chats; you can view and edit what it remembers in Settings.
Connectors Links to apps such as Google Drive, Gmail, or GitHub, built on the open Model Context Protocol (MCP) (see MCP Servers).
Skills Folders of instructions that teach Claude a repeatable task; Claude loads a skill only when it’s relevant (see Skills).
Research A research agent that runs many web searches and writes a report with sources (paid plans).

41.5 Claude inside other apps

As of Oct 6, 2026 · Official docs: Get started with Claude in Chrome · Claude for Microsoft 365 · Claude in Google Docs, Sheets, and Slides · What is Claude Tag?

  • Claude in Chrome: a Chrome extension with a side panel. Claude reads the page you’re on and can click, type, and fill in forms. Paid plans (the side panel is in beta). Anthropic warns about prompt injection: a web page can hide instructions aimed at Claude (see Limits, Risks, and Responsible Use).
  • Claude for Microsoft 365: add-ins for Excel, PowerPoint, and Word (generally available on paid plans) and Outlook (beta). Claude works directly in the open workbook, deck, document, or inbox.
  • Claude for Google Workspace: the same idea for Google Docs, Sheets, and Slides (beta, paid plans). This is different from the Google Drive connector, which lets claude.ai search your Drive while you chat.
  • Claude Tag: tag @Claude in a Slack channel, and it does the work in the open as your organization’s shared teammate, for coding and non-coding tasks. Team and Enterprise plans (beta); channel work is billed to the organization.

41.6 Claude Code: one agent, many places

As of Oct 6, 2026 · Official docs: Claude Code overview · Platforms and integrations

Claude Code is an agent: you describe a goal, and it reads your files, edits code, runs commands, and checks the result. Its permission mode decides which actions need your approval first (see Permissions, Modes, and Safety). It is included in every paid plan (not Free), and you can also pay for it per use with a developer (Console) account. The same engine runs in several places:

  • Terminal (CLI): the claude command. It is the most complete version and the one this course uses (see Installing Claude Code).
  • Code editors: extensions for VS Code (and editors built on it, such as Cursor) and for JetBrains editors such as PyCharm (the JetBrains plugin is still labeled beta).
  • Desktop app: the Code tab.
  • Cloud: sessions started at claude.ai/code run on Anthropic’s computers and keep going after you disconnect.
  • Phone: the mobile app’s Code tab, which can also steer a session running on your own computer (Remote Control).

Claude Code Beyond the Terminal compares these surfaces.

41.7 The Claude Developer Platform

As of Oct 6, 2026 · Official docs: Claude Platform docs · Agent SDK overview · Managed Agents overview

For people who build Claude into their own software:

  • Claude API: your program sends Claude a request and gets a reply back. You pay per token (a chunk of text, roughly part of a word; see How LLMs Work). This is billed separately from any app subscription (see APIs, API Keys, and Third-Party Services).
  • Claude Console (platform.claude.com): the website where developers create API keys, test prompts, and see usage and bills.
  • Client SDKs: official libraries for Python, TypeScript, Java, Go, and other languages that make calling the API easier.
  • Agent SDK: “Claude Code as a library”: the same tools and agent loop that power Claude Code, inside your own Python or TypeScript program.
  • Managed Agents (beta): Anthropic hosts the whole agent for you, including a cloud sandbox where it runs.

Companies can also buy Claude models through Amazon Bedrock, Google Cloud, and Microsoft Foundry.

41.8 Names that are easy to mix up

As of Oct 6, 2026 · Official docs: Claude Code in Slack · Projects in Claude Code · Share session output as artifacts

These two… …differ like this
claude.ai vs. Claude Console claude.ai is the chat app. The Console (platform.claude.com) is the developer dashboard for API keys and API bills. A paid claude.ai plan does not include API usage.
Claude Tag vs. Claude Code in Slack Both answer @Claude in Slack. Claude Tag is the organization’s shared teammate (Team and Enterprise). Claude Code in Slack is the earlier version: it starts a cloud coding session under your own account (Pro and Max), and only in Slack workspaces that are not connected to Claude Tag.
Projects in claude.ai vs. the new Projects A classic project is a folder of chats, files, and instructions. The new Projects (public beta, rolling out to some Pro and Max users, starting with Claude Code) is one conversation in which Claude runs many parallel cloud sessions for you. Existing projects keep working.
Artifacts in chat vs. artifacts from Claude Code The same idea. Claude Code can publish its work (for example, an annotated list of code changes) as a live page on claude.ai that stays private until you share it.
Claude Desktop vs. Claude Code Desktop The same app; “Claude Code Desktop” means its Code tab.
Claude in Chrome vs. Claude Code’s Chrome integration The same extension, used on its own or driven by Claude Code.
Deeper dive: Specialized Claude products

As of Oct 6, 2026 · Official docs: Claude Science overview · Use Claude Security · Claude Fable and Mythos 5.1

  • Claude Science (beta): a separate desktop app that pairs Claude with a sandboxed analysis environment (Python, R, shell) and connectors to scientific databases. On for Pro and Max; Team and Enterprise owners must turn it on.
  • Claude Security (beta, Enterprise only): scans a codebase for security weaknesses and proposes fixes for a person to review.
  • Claude for Government: a version of Claude for government agencies.
  • Claude Mythos 5.1: an invitation-only model for vetted cybersecurity and biology research groups. Claude Fable 5.1 is the same underlying model with extra safeguards, so everyone else can use it.

41.9 Key takeaways

  • “Claude” can mean the model, the apps, Claude Code, or the API.
  • The Free plan does not include Claude Code, and no subscription includes API usage.
  • Names and plans change quickly: check the date badges and official links.

Practice Questions

Easy

Question 1 · Multiple choice

Which description fits Claude Code?

  1. A website where you chat with Claude about any topic
  2. An agent that reads your project, edits files, and runs commands to complete coding tasks
  3. A dashboard for creating API keys and viewing API bills
  4. A Slack app that acts as your organization’s shared teammate
Suggested answer

b. Claude Code is Anthropic’s coding agent. Option a describes claude.ai, option c describes the Claude Console, and option d describes Claude Tag.

Question 2 · Short answer

The word “Claude” can refer to four different things. Name them.

Suggested answer
  1. The model: the AI itself (the Fable, Opus, Sonnet, and Haiku models).
  2. The Claude apps: claude.ai, Claude Desktop, and the mobile apps.
  3. Claude Code: the coding agent.
  4. The Claude API (part of the Claude Developer Platform): how programs use Claude, paid per use.

Question 3 · True or false

The Free plan includes Claude Code.

Suggested answer

False. Claude Code is included in the paid plans (Pro, Max, Team, and Enterprise). You can also pay for it per use with a Console (API) account. The Free plan includes chat, artifacts, connectors, and more, but not Claude Code.

Question 4 · Matching

Match each product with its description.

Product Description
1. claude.ai A. Developer dashboard for API keys and API bills
2. Claude Desktop B. @Claude as a shared teammate in Slack channels
3. Claude in Chrome C. Chat website that works in any browser
4. Claude Tag D. Browser extension that reads and acts on web pages
5. Claude Console E. Installed app for Mac and Windows with a Code tab
Suggested answer

1 → C, 2 → E, 3 → D, 4 → B, 5 → A.

Question 5 · Multiple choice

Where do you use Claude Tag?

  1. In Slack
  2. In Excel
  3. In VS Code
  4. In the Claude Console
Suggested answer

a. Claude Tag puts @Claude into Slack channels as a shared teammate (Team and Enterprise plans). Excel has Claude for Microsoft 365, VS Code has the Claude Code extension, and the Console is the developer dashboard.

Question 6 · True or false

“Claude for Google Workspace” and the Google Drive connector are two names for the same feature.

Suggested answer

False. Claude for Google Workspace puts Claude in a sidebar inside Google Docs, Sheets, and Slides, where it edits the open file. The Google Drive connector works the other way around: while you chat at claude.ai, Claude can search and read files in your Drive.

Suggested answer

Claude for Microsoft 365, specifically the Excel add-in. It opens Claude in a sidebar inside Excel and works on the open workbook. It requires a paid plan (Pro, Max, Team, or Enterprise).

Question 8 · Scenario

Sam has a Pro plan. His student club chats in a Slack workspace that is not connected to any Claude organization. He wants to type @Claude with a bug report and get back a pull request.

  1. Which Claude product can he use, and under whose account does the work run?
  2. Why can’t he use Claude Tag?
Suggested answer
  1. Claude Code in Slack (the earlier Slack integration). It starts a Claude Code cloud session under Sam’s own Claude account and plan.
  2. Claude Tag is only available on Team and Enterprise plans; it acts as an organization’s shared teammate. A Pro plan doesn’t include it.

Question 9 · Short answer

For each product, say where you use it: in a web browser, in an installed app or program, inside another app, or from your own code.

  1. claude.ai
  2. Claude Desktop
  3. The Claude Code CLI
  4. Claude for Microsoft 365
  5. The Claude API

  1. Web browser.
  2. Installed app (Mac, Windows; Linux in beta).
  3. Installed program that you run in a terminal.
  4. Inside another app (Excel, Word, PowerPoint, Outlook).
  5. From your own code (your program sends requests to Anthropic).

Note: in all five cases the model itself runs on Anthropic’s servers. What differs is where you interact with Claude and what Claude can reach (for example, the CLI can read and edit files on your computer).

Question 10 · Multiple choice

In claude.ai, what is a classic project?

  1. A Git repository that Claude creates for you
  2. A workspace that groups chats with uploaded files and standing instructions
  3. A paid add-on that unlocks the Opus models
  4. A Claude Code session that runs in the cloud
Suggested answer

b. A project is a workspace with its own chats, files (its knowledge), and instructions. It is not a Git repository (a), not a paid add-on (Free users can create up to 5 projects) (c), and not a cloud session (d). The new Projects beta does coordinate cloud sessions, but it is a different, newer feature.

Question 11 · Short answer

What is an artifact? Give two examples, and name the three artifact templates.

Suggested answer

An artifact is something Claude makes for you that you would put in front of someone else. It opens beside the conversation, you can edit it and come back to it, and you can share it by link. Examples: a document, a slide deck, a design or mockup, a dashboard, a small interactive tool. The templates are Claude Design, Claude Slides, and Claude Docs (beta, paid plans). Claude Code can also publish artifacts.

Question 12 · Short answer

What happened to Cowork in September 2026, and how can you tell whether your account has the new experience yet?

Suggested answer

Anthropic began merging chat and Cowork into one “Claude” conversation. You no longer choose a mode: Claude decides whether a request needs a quick answer or a longer task, which can keep running in the cloud. The change is rolling out in stages (Pro and Max first). If your message box still shows separate “Chat” and “Cowork” options, you still have the older experience.

Hard

Question 14 · Find the bug

A classmate says: “I already pay for Claude Pro, so the Python app I’m building can call the Claude API for free.” What is wrong with this reasoning, and what would the classmate actually need?

Suggested answer

A Claude subscription and the Claude API are separate products. Pro covers the Claude apps and Claude Code (within usage limits), but it does not include API usage. To call the API from a program, the classmate needs a Claude Console account (platform.claude.com), an API key, and API credit; the app is then billed per token.

Question 15 · Scenario

A small-business owner wants three things:

  1. A weekly summary of the sales spreadsheets she keeps on her computer.
  2. An assistant her six employees can tag in their shared Slack channels.
  3. A chatbot on her company website that answers customer questions.

Recommend a Claude product for each, and explain why.

Suggested answer
  1. The Claude apps, for example Claude Desktop, which can work with files on her computer and can repeat the task on a schedule (the app must be open when a task uses local files), or Claude for Excel if the work happens inside one workbook. These need a paid plan.
  2. Claude Tag: it acts as a shared @Claude teammate in Slack channels. It requires a Team or Enterprise plan.
  3. The Claude API (Claude Developer Platform): a website chatbot is her own software calling Claude, so it needs an API key from the Console and is billed per token. A subscription cannot be embedded in a website.

A good answer matches each need to a product and notes the plan or billing model it requires.

Question 16 · Compare

How is the Claude in Chrome extension related to Claude Code’s Chrome integration? Why should you be careful when letting Claude control your browser?

Suggested answer

They use the same extension. You can use Claude in Chrome on its own (in the side panel), or let Claude Code drive your browser through it, for example to test a web app you are building.

Be careful because Claude acts in your real browser with your logins, so it can do anything you could do on those sites. Also, web pages can contain prompt injection: hidden text that tries to give Claude instructions. Keep an eye on what it does, especially on sites with money, email, or private data.

Question 17 · Short answer

A friend says, “Claude Code is just a website.” Correct this. Name at least four places where you can use Claude Code, and say which one this course uses.

Suggested answer

Claude Code is an agent that runs in many places: the terminal (the claude command), code editors (VS Code and JetBrains extensions), the Desktop app’s Code tab, the cloud (sessions at claude.ai/code), and the mobile app’s Code tab (including Remote Control of a session on your computer). There is a web version, but it is only one surface. This course uses the terminal version.

Question 18 · Long answer

Two students argue about “Projects”. One says a project is a folder of chats and files with instructions; the other says a project is a conversation where Claude runs many coding sessions in parallel. Explain how both can be right, and why the date badges on Claude pages matter for questions like this.

Suggested answer

Both describe real features. The classic claude.ai project is a workspace with chats, uploaded files, and instructions. The new Projects (public beta, rolling out to some Pro and Max users, starting with Claude Code) is one conversation in which Claude starts and tracks many parallel cloud sessions. Existing classic projects keep working.

Anthropic renames, merges, and redesigns products often (Cowork merging into chat is another example). A description is only correct as of a certain date, so check the “As of” badge, follow the official link, and compare with what you see in your own account.

Question 19 · Hands-on

Sign in to claude.ai (any plan is fine) and find:

  1. Your current plan (in Settings).
  2. Whether your message box shows separate “Chat” and “Cowork” options.
  3. Whether you can see a “Code” entry anywhere in the app.
  4. Where your projects and artifacts are listed.

Compare what you find with the map on this page. Write down anything that has changed since October 6, 2026.

Suggested answer

Answers depend on your account and the date. A good answer:

  • names the plan (for example Free or Pro);
  • says whether the account has the older (separate Chat and Cowork) or newer (one conversation) experience (on the Free plan you won’t see Cowork at all, because it is a paid feature);
  • notes whether Code appears (it requires a paid plan);
  • explains where Projects and Artifacts appear (in the sidebar or an Artifacts tab);
  • lists at least one difference from this page, or states that nothing differs, with the date you checked.
